# AGENTS.md

The instructions for every agent working on this repository (Codex, OpenCode, Claude Code or any other) are in `CLAUDE.md`: read it first and follow it as written, including the rule files of `.claude/rules/` that its "Rules by area" names for the area you work in. A skill it names (skill `x`) is `.claude/skills/x/SKILL.md`; read it before the work it covers. "Working alongside others" in `CLAUDE.md` is how the team keeps its work in sync. Where it says what Claude may do (merge its own PR once CI is green), that holds for any agent of the team; the hook that keeps Claude Code's pushes off `main` does not bind other harnesses, so only the ruleset on `main` does: never push to `main`.
