Obnovit databázi ze zálohy?

Web se vrátí do stavu z {{ createdAt() }}, ze zálohy {{ backup().fileName }}.

  • Co přibylo nebo se změnilo po vytvoření zálohy (registrace, aktuality, nastavení, přiřazené platby), se ztratí. Platby z banky za posledních 90 dní se při dalším stažení z Fio doplní znovu.
  • Co se po vytvoření zálohy změnilo kvůli bezpečnosti nebo ochraně údajů, zůstane: vymazaní dárci zůstanou vymazaní, hesla, přístupové klíče, druhé ověření a role správců zůstanou, jak jsou teď, a historie správy se nezkrátí.
  • Potvrzení o daru vydaná po vytvoření zálohy z databáze zmizí. Jejich čísla se už nikomu nepřidělí: kdo si potvrzení stáhne znovu, dostane ho s novým číslem.
  • Současný stav se před obnovou sám uloží jako záloha „Před obnovou“, takže se k němu můžete vrátit stejným tlačítkem.
  • Web bude několik minut nedostupný. Obnova ukončí každé přihlášení: všichni, vy i dárci, se přihlásí znovu a konektor v claude.ai je potřeba připojit znovu. Když se obnova nepovede, web poběží dál s dnešními daty.
