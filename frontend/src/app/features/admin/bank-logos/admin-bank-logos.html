Loga bank

Vedle čísel českých účtů web ukazuje kulaté logo banky. Server ho stáhne z adresy, kterou tu zadáte, upraví ho na malý čtverec a posílá ho sám, takže prohlížeč dárce nekontaktuje banku ani Apple. Banka bez loga má u svých účtů zkratku názvu.

Server přijme jen adresu ikony aplikace z App Store (is1-ssl.mzstatic.com až is5-ssl.mzstatic.com) nebo obrázku z webu té banky, vždy přes https a bez části za otazníkem. Obrázek musí být PNG nebo JPEG. Jednou týdně server loga stáhne znovu; když se to nepovede, ukazuje dál dosavadní logo.
